# Cloud & Space DJ — Student Portfolio

My personal portfolio for the **AWS Student Builder Challenge: Build Your Tech Superpower**.

Theme: *Cloud by day, aspiring space DJ by night.* The site is built around an
interactive **Space DJ deck** — a set of glowing pads that drop a sound and cue
up each section, the way a DJ cues a track.

🔗 **Live site:** `https://YOUR-AMPLIFY-URL` _(update after deploy)_
🛠 **Stack:** Vite + React, deployed on **AWS Amplify Hosting**

---

## The creative feature — the Space DJ deck

The centerpiece is an interactive deck in the hero:

- An **original SVG DJ booth** — two vinyl turntables and a mixer, drawn in
  code (no stock images). The records spin and a VU meter animates while the
  track plays, and the faders twitch each time you hit a pad.
- A **"Drop the track" play button** that loops an **original synthwave track**
  I generated myself (see _Assets_ below) — so there are no licensing questions.
- **5 pads**, one per section (About, The Rig, The Set List, Achievements, Transmission).
- Hitting a pad **synthesizes a short sound** with the Web Audio API (no audio
  files — each pad is a tiny oscillator "drop") and **smooth-scrolls** to that section.
- Works by **click/tap or the keyboard keys `1`–`5`**.
- An **LED ticker** types out rotating messages, and a **visible hint** below the
  pads tells visitors exactly how to use it:
  _"Hit a pad or press 1–5. Each one drops a sound and cues up that section."_

It's interactive, it works, and it never blocks navigation — the normal top nav
and anchor links work independently.

## Assets (all original)

- **DJ booth graphic:** hand-authored SVG in `src/components/DJBooth.jsx`. No
  stock images, so it stays sharp at any size and matches the theme exactly.
- **Music loop:** `public/space-dj-loop.mp3` is an original 11s synthwave loop
  generated by `scripts/make_loop.py` (pure numpy synthesis → ffmpeg). Regenerate
  it any time with `python3 scripts/make_loop.py`. Because it's self-generated,
  it's royalty-free and owned outright — nothing to attribute or license.
- **Pad sounds:** synthesized at runtime with the Web Audio API — no files.
- **Starfield:** a live HTML5 canvas animation (`src/components/Starfield.jsx`).

## Deploy to AWS Amplify (from GitHub)

1. Push this `portfolio/` folder to a **GitHub repository**.
2. In the AWS console open **AWS Amplify → Create new app → Host web app**.
3. Choose **GitHub**, authorize, and pick your repo + branch.
4. Amplify auto-detects the build settings from **`amplify.yml`** in this repo.
   (Framework: Vite/React, build command `npm run build`, output `dist`.)
5. Click **Save and deploy**. In ~1–2 minutes you get a live
   `https://<branch>.<app-id>.amplifyapp.com` URL.
6. Paste that URL into this README and your hackathon submission.

Every future `git push` to the connected branch redeploys automatically.
